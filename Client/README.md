This is the client application for terminal chess – an application made for the PPY project.
To run this application, go into your windows cmd or PowerShell (it doesn't support bash for now :(( ). Go into the application folder and type: "python terminal_chess_client_application.py" it should then run without any problems. 
The application for now supports only local games with a friend.
To move the pieces, use the standard chess notation.
If you need any help with the functionalities or the notation, type ":help" during a game.
